# Solar PV Maximum Power Point Tracking (MPPT)

## Overview
This project implements Maximum Power Point Tracking (MPPT) for a photovoltaic (PV) system using MATLAB/Simulink. The objective is to maximize power extraction under varying irradiance conditions.

## Features
- MATLAB/Simulink implementation
- PV array modeling
- MPPT algorithm
- Performance under varying irradiance
- Output power and voltage analysis

## Tools Used
- MATLAB
- Simulink

## Results
The simulation demonstrates successful tracking of the maximum power point and improved energy extraction from the PV system.
